# Validação da exportação CSV

1. Rode o projeto local normalmente.
2. Entre em Dashboard > Solicitações.
3. Use a busca e/ou o filtro de status, se desejar.
4. Clique em **Exportar CSV**.
5. O arquivo gerado terá nome semelhante a `solicitacoes-eac-37-2026-08-18.csv`.
6. A exportação respeita os filtros visíveis na tela.
7. O CSV usa `;` como separador e BOM UTF-8 para abrir corretamente no Excel em pt-BR.

Campos exportados:
- Código
- Data/Hora
- Solicitante
- Beneficiário
- E-mail
- Telefone
- Tipo solicitante
- Equipe
- Cor
- Tamanho
- Quantidade solicitada
- Quantidade coberta
- Quantidade entregue
- Quantidade sem cobertura
- Situação do item
- Status da solicitação
- Status do e-mail
